# Kirby's TV

Projeto de site estático sobre Kirby, com páginas de apresentação, matéria, jogos e votação.

## Objetivo

O site tem como finalidade apresentar o universo de Kirby de forma visual e organizada, destacando:

- a página inicial com apresentação geral;
- uma página de matéria editorial;
- uma página de jogos;
- uma página de votação.

## Tecnologias utilizadas

- HTML5
- Áudio WAV local em `midia/`
- Imagens locais em `imagens/`

Este projeto não utiliza CSS nem JavaScript, conforme a orientação da Avaliação 01.

## Como abrir o projeto

1. Acesse a pasta do projeto.
2. Abra o arquivo `index.html` em qualquer navegador.
3. Navegue pelas páginas usando o menu principal.

## Páginas disponíveis

- `index.html`: página inicial e apresentação do tema.
- `materia.html`: artigo ou matéria principal.
- `jogos.html`: lista de jogos relacionados ao tema.
- `votação.html`: página de votação ou enquete.
- `midia/melodia-original.wav`: melodia curta original tocada na página de jogos.
