# Contribuição

## Como colaborar

1. Faça uma cópia local do projeto.
2. Crie uma branch para a alteração.
3. Ajuste o conteúdo ou a estrutura conforme a necessidade.
4. Teste a navegação no navegador.
5. Envie a alteração para revisão.

## Padrões esperados

- manter a navegação consistente;
- preservar a organização das páginas;
- usar nomes claros para arquivos e imagens;
- documentar mudanças relevantes.
