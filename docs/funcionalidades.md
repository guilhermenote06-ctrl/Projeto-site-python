# Funcionalidades do projeto

## Funcionalidade geral

O site tem como objetivo apresentar um tema específico com linguagem visual simples, organizada e navegação direta entre as seções.

## Funcionalidades por página

### Página inicial
- apresenta o tema principal;
- exibe o nome do projeto;
- referencia os elementos mais importantes do conteúdo;
- direciona o usuário para outras áreas do site.

### Matéria
- informa o conteúdo editorial principal;
- pode conter texto, títulos e data de publicação;
- organiza a informação de forma clara e legível.

### Jogos
- apresenta dois jogos com imagens acessíveis e legendas;
- organiza informações em listas e em uma tabela de dados;
- oferece uma melodia original com controles de reprodução.

### Votação
- apresenta uma enquete com três opções de voto;
- inclui campos de tipos diferentes, identificados por rótulos e com validação nativa;
- demonstra a interação no navegador, mas não armazena nem contabiliza respostas.

## Benefícios do projeto

- fácil entendimento para o usuário;
- navegação rápida por páginas;
- organização visual simples;
- manutenção direta do conteúdo sem complexidade de framework.

## Possíveis evoluções

- adicionar estilos em CSS separados;
- incluir animações leves;
- conectar a votação a um serviço que armazene e contabilize respostas;
- adicionar mais páginas de conteúdo;
- incluir responsividade para celulares.
